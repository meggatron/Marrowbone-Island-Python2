Marrowbone Island 2 – Day 1

Project Summary:
This is the starting version of our Python 2 course game, Marrowbone Island.

We are refactoring the Python 1 game by organizing the code into separate files and modules. The game works the same way, but the code is now easier to organize, read, and expand.

We’ll be building on this structure throughout the course.

Folder Structure:
main.py           - Starts the game and runs the main game loop
assets/intro.txt  - Intro text shown at the start
assets/log.txt    - Records locations visited by the player
assets/map.jpg    - Map image of the island
game/__init__.py  - Makes game a Python package
game/locations.py - Location functions and game logic
game/player.py    - Player name and inventory

How to Play:
Run main.py to start the game.
